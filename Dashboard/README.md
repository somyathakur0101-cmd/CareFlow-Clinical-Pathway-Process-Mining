# CareFlow Dashboard

This folder contains the interactive Streamlit dashboard for the CareFlow Clinical Pathway Process Mining project.

## Features
- Interactive dashboard
- Appointment date filters
- Doctor selection
- Patient flow analysis
- Hospital OPD data analytics
- Key performance indicators and visualizations

## Technology Used
- Python
- Streamlit
- Pandas
- Plotly
- Matplotlib
