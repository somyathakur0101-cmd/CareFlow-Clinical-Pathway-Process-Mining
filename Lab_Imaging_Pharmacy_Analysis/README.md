# Lab, Imaging and Pharmacy Analysis – CareFlow Project

## Objective
To analyse laboratory activities, imaging requests and pharmacy transactions in the hospital OPD dataset.

## Analysis Performed
1. Laboratory activity analysis
2. Imaging request analysis
3. Pharmacy transaction analysis
4. Monthly activity trends
5. Processing duration analysis
6. Data quality analysis

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Deliverables
- Laboratory analysis charts and reports
- Imaging analysis charts and reports
- Pharmacy analysis charts and reports
- Department-wise summary CSV files
- Data quality report
- Python analysis notebook
