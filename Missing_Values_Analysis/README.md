# Member 2 – Missing Values Analysis

## Objective
To identify missing values in each column of the HospitalOPD dataset.

## Dataset Details
- Total Rows: 62,422
- Total Columns: 25

## Key Findings
- Unnamed: 2: 100% missing values
- Lab-related columns: 71.12% missing values
- Imaging-related columns: 91.15% – 91.17% missing values
- Pharmacy-related columns: 99.52% missing values

## Conclusion
Missing values are mainly concentrated in lab, imaging, and pharmacy-related columns.
