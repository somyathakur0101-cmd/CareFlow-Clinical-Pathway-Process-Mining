# Overall Hospital Analysis – CareFlow

## Project Overview
This section contains the overall Exploratory Data Analysis (EDA) of the CareFlow Clinical Pathway Process Mining project.

## Analysis Performed

1. Hospital Workflow Distribution
2. Monthly Appointment Trend
3. Unique Patients by Workflow
4. Data Quality Analysis

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Output Files

The Analysis_Output folder contains:

- 01_workflow_distribution.png
- 02_monthly_appointments.png
- 03_patient_workflow.png
- 04_data_quality.png
- overall_summary.csv
- workflow_summary.csv
- monthly_appointments.csv
- data_quality_report.csv

## Objective
To understand hospital workflow patterns, monthly appointment trends, patient distribution and data quality through exploratory data analysis.

## Status
EDA analysis completed. Results are prepared for integration into the final project report and dashboard.
