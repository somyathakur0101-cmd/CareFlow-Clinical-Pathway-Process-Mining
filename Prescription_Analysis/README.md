# Prescription Analysis – CareFlow Project

## Objective
To analyse prescription records and understand prescription trends, doctor-wise distribution, processing duration and waiting time.

## Analysis Performed
1. Total prescription analysis
2. Doctor-wise prescription analysis
3. Monthly prescription trends
4. Prescription duration analysis
5. Appointment-to-prescription waiting time
6. Data quality analysis

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Deliverables
- Four visualizations
- Prescription summary CSV
- Doctor-wise prescription count CSV
- Prescription quality report CSV

## Key Findings

1. Total unique prescriptions analysed: 50,568.
2. Total doctors involved: 98.
3. October 2025 recorded the highest monthly prescription count: 7,808.
4. Median appointment-to-prescription waiting time: 27 minutes.
5. Around 66.28% of prescription duration records had zero duration. This indicates a timestamp quality issue requiring further investigation.

## Conclusion

The analysis helped understand doctor-wise prescription distribution, monthly prescription trends, processing duration, waiting time and data quality.
