# Key Findings – Prescription Analysis

## 1. Doctor-wise Prescription Analysis
The dataset contains 50,568 unique prescription orders across 98 prescription doctors.

## 2. Medicine Distribution
Only 302 records contain medicine names, indicating significant missing information in medicine-level data.

## 3. Prescription Data Quality
52 records were flagged where prescription end timestamps occurred before prescription start timestamps.

## Conclusion
Prescription analysis helps understand doctor-wise prescription activity, monthly trends, medicine distribution and data quality issues. The findings can support better healthcare data monitoring and reporting.
